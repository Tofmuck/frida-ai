Contact address

You can write about Frida_V4, FridaDev, the frida-ai site, the M6 paper, a working hypothesis, a documentation issue, or a precise proposal.

tofmuck@frida-ai.fr

Exchanges take place in French or English. A response time of a few days is normal: the project is independent, and the site follows the real pace of the technical work.

Why write

What the project is looking for

Frida does not need general noise around a vague idea. What matters are conversations that improve a repository, a module, a hypothesis, a document, or an evaluation protocol.

The following are welcome:

  • Argued feedback on the M6 paper
  • Questions about architecture choices across Frida_V4 and FridaDev
  • Collaboration proposals on a precise module, surface, or evaluation
  • References to related work that has been overlooked, under-read, or should be integrated
  • Documentary, conceptual, or technical contributions that are actually situated

Less relevant: generic outreach, vague partnerships, or commercial solicitations unrelated to the actual problems being worked on.

Contribute

The construction site is open

The project is open, but not undifferentiated. Useful contributions are those that clarify a real problem, reduce ambiguity, improve a contract, strengthen evaluation, or make the site more exact.

Profiles sought

Several kinds of input have real value for the project's current state:

Swift / macOS Python / Flask RAG / memory LLM evaluation Philosophy of language Hermeneutics Technical documentation Academic review

A contribution can be light or heavy: flagging an inconsistency, reviewing a text, proposing a tighter formulation, opening a discussion about an architecture choice, building an evaluation protocol, correcting a site page, or working directly in the code.
